# ``ExplorerPresentation``

Application ownership, retained observation and truthful Machine Room projections.

## Overview

This target owns the observable research, server and guided client state,
the bounded activity actor, and the read-only values projected into native
charts. UI animation never owns a transport, modifies observation counts,
or substitutes for cancellation and joining.

The Machine Room has two distinct scopes: eligible server tool handlers
and opt-in guided-client SDK exchange metadata. Never infer a comprehensive
network trace from either.
