# ``ExplorerDomain``

Owned research models, source identity, normalized revisions and finite projections.

## Overview

This target is the source-independent domain contract. A candidate is not a
revision. Resolve it into an outline, then reuse the exact snapshot and part
identity for subsequent operations. A missing reference list is distinct from
a known empty list. Reference metadata is not independent verification.

The fictional Riverglass fixture format is owned by this example; it is not
a decoder for public Wikimedia responses. The selected source profile determines
which provider, project and normalizer identities are admitted.
