# Revision identity and evidence

Keep all research results tied to the exact admitted normalized revision.

## Overview

`SnapshotID` includes the provider, project, page ID, revision ID and
normalizer version. A `PartLocation` contains that identity and its part ID.
The outline supplies the locators used by section and reference operations.

Never synthesize an ID from a display title, silently update the revision
under a reader, or replace a missing live result with the fictional collection.
A user can explicitly request a new outline. Render truncation, absent
content and unresolved reference metadata distinctly.

`ExplorerLimits` bounds the depth, parts, text bytes, response bytes, cache
entries, cache content bytes and snapshot lifetime. Initializers reject
values outside the example profile. These constraints are admission and
projection contracts, not claims about the maximum size of Wikipedia.
